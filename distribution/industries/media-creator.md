## Distribution thesis

**Primary user need:** Audience trust, distribution rights and recurring engagement. Choose channels based on where the actual buyer discovers, evaluates and adopts the product, not simply on follower count.

## Funnel and retention measurement

**North-star candidates:** Subscriber activation; return consumption; paid retention. Define the event precisely, log the denominator and review cohorts. Impressions, views, likes, app installs and email signups are upstream indicators, not substitutes for successful use.

## Launch experiment

1. Interview five or more relevant prospects if feasible; record actual discovery behavior and buying objections.
2. Choose a narrow segment and one high-intent channel; write a specific offer and proof requirement.
3. Produce a search guide, one short-form demonstration and a partner/community pitch suited to the sector.
4. Localize with the [country playbook](../countries/README.md), including language, payment and regulatory checks.
5. Instrument campaign → landing → signup → first value event → repeat value, with privacy-safe analytics.
6. Run a limited pilot, track CAC and retention, then continue, revise or stop based on predefined guardrails.

## Content and distribution test cases

| Test | Expected outcome |
| --- | --- |
| Ad claim versus landing | Same truthful product promise |
| Demo versus actual product | No unsupported capability or testimonial |
| Signup versus activation | Server-verified user value event |
| Country/payment eligibility | Real supported merchant and checkout |
| Consent and tracking | Applicable consent/opt-out respected |
| Repeat value | Cohort return and task completion measured |
