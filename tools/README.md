[← Home](../README.md) · [Choose a topic](../docs/START-HERE.md)

**How to choose:** start with the failure you are investigating, not a paid product. Prefer tools with transparent pricing, usable documentation, data controls, exportability, integrations and a workflow you can maintain. The list is descriptive rather than a ranking or endorsement. Plans and free-tier limits change.

## Lean tool stacks

- **Zero/low budget web MVP:** browser DevTools + Playwright + Vitest/Testing Library + axe-core/WAVE + Lighthouse + GitHub Actions; add basic error monitoring.
- **SaaS:** add API collection/contract tests, payment sandbox, role/tenant isolation checks, observability and consent-aware funnel analytics.
- **Mobile:** real physical devices + TestFlight/Play testing + Maestro/Appium as appropriate + crash monitoring + store review guides.
- **AI:** ordinary app checks plus curated eval dataset, prompt injection and tool-authorization tests, trace review and model-change regressions.
- **International:** pseudolocalization, a string-management workflow, RTL tests and native-language review before launch.

## Due diligence before buying

Review current price/seat limits, supported devices and browsers, data-processing location, recording/redaction controls, accessibility, vendor lock-in and export, SSO, uptime commitments and feature maturity. **No sponsored placement or guaranteed free perks.**
