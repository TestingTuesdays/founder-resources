# Growth, retention, virality and network-effect metrics

[← Growth](README.md)

| Metric | Formula | Caveat |
| --- | --- | --- |
| CTR | Clicks / impressions | Platform definitions vary |
| CPC | Spend / clicks | Paid only |
| CPM | Spend / impressions × 1000 | Reach is not activation |
| Signup conversion | Signups / eligible visitors | Define bot exclusions |
| Activation | Users completing value event / eligible new users | Define value event |
| CAC | Acquisition cost / acquired customers | Paid vs blended |
| D7 retention | Eligible cohort active on day 7 / starting cohort | Define active and timezone |
| Churn | Lost customers / starting customers | State account or revenue |
| WAU/MAU | Weekly active / monthly active | Frequency dependent |
| Referral activation | Activated referrals / valid invites | Exclude spam |
| Viral coefficient | Invites per user × activation per invite | Does not itself prove network effects |
| Marketplace fill | Successful matches / eligible requests | Measure match quality |

**Example, illustrative only:** 1,000 visitors → 100 signups = 10% signup conversion. If 40 signups complete the first value task, activation = 40% of signups and 4% of visitors. Report denominators and retention by cohort. Network effects require evidence that product value rises with relevant participant density; referral volume alone is insufficient.
