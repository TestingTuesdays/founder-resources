## Founder product demo — 30 seconds

| Seconds | Narration | Visual |
| --- | --- | --- |
| 0–3 | This step stopped people from finishing signup | Actual interface; clear captions |
| 3–10 | We observed a user try to complete the task | Consent-safe reconstruction |
| 10–20 | The confusing part was the following step | Before/after annotated screen |
| 20–26 | We changed the interface and retested | Only claim measured result if tested |
| 26–30 | Try it and share where you get stuck | Product CTA |

## Educational explainer — 45 seconds

Hook: “A signup is not the same as activation.” Define the value event, show a clearly labeled hypothetical example, give the viewer a way to measure activation and end with a useful CTA. Add primary-source links for factual claims.

## Production formats

Face-to-camera, UGC demonstration, faceless narration plus licensed b-roll, screen recording, green-screen commentary and documentary-style explainer. For each record the hook, voiceover, cut-by-cut visuals, captions, rights, disclosures, description, hashtags when relevant, CTA and performance metrics. Do not invent customer testimonials.
