# Startup School and founder learning curriculum

[← Skills](../README.md) · [Detailed guide](../../growth/startup-learning.md)

## Inputs

Founder stage, target users, actual product, jurisdiction, authorized data, current primary sources and named owner.

## Procedure

1. Start with YC Startup School and YC Library for founder fundamentals.
2. Use a16z articles/videos for market, distribution, fundraising and company-building perspectives.
3. Watch primary founder/investor interviews and distinguish opinion from empirical fact.
4. Record each resource's target stage, topic, format, author, source and date.
5. Pair each lesson with one experiment in the founder's own product.
6. Update the library when content is unavailable or materially outdated.

## Completion

Deliver topic-indexed learning catalog with source urls and action assignments. Distinguish verified facts, hypotheses, observed metrics and unverified leads. Record next review date and responsible owner.

## Safety

No invented traction, fake testimonials, unauthorized data sharing, guaranteed algorithm reach or unsupported legal/tax advice. Use qualified professional review for securities, tax and entity matters.
