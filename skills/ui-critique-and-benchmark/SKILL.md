# UI critique, inspiration research and ethical benchmarking — reusable skill

[← Skill library](../README.md) · [Detailed guide](../../design-growth/ui-critique-and-benchmark.md)

## Inputs

Live or staging URL, target audience, core user journey, representative devices, current product facts and authorized testing access.

## Procedure

1. Select comparable apps by target task, platform, accessibility and audience.
2. Capture public reference URLs and note pattern, date, screen and user problem.
3. Separate inspiration from evidence that a pattern works for your users.
4. Evaluate visual hierarchy, copy, responsiveness, empty states, feedback and trust.
5. Create two original alternatives and test task completion with representative users.
6. Check licensing, trademarks, privacy and avoid copying protected artwork/assets.

## Output

A prioritized audit: URL/component, problem, impact, evidence, recommended change, owner, expected outcome, verification status and comparable retest.

## Rules

No guaranteed rankings, fabricated testimonials, hidden SEO manipulation or unlicensed copied assets. Distinguish research from tested results. Use the [audit template](../../templates/design-growth-audit.md).
