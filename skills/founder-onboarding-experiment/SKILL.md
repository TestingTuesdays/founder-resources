# Founder onboarding and activation experiment

[← Skills](../README.md) · [Guide](../../docs/founder-onboarding-experiment.md)

## Inputs

Versioned product, real target user task, synthetic test accounts, authorized environment and named reviewer.

## Procedure

1. Define the activation event as a user-achieved outcome, not a page view.
2. Recruit intended users and test first-run comprehension without coaching.
3. Measure completion, failure reasons and time to first value.
4. Audit empty states, permissions, verification, email delivery and mobile errors.
5. Compare variants with a pre-registered hypothesis and guardrail.
6. Retest post-release and record whether improvement persists.

## Completion criteria

Evidence-backed issue register with observed outcomes, severity, owner, fix, build and retest. Separate hypotheses and proposed tests from executed tests.

## Privacy and safety

Never publish participant identities, payment details, credentials or unapproved security findings. Escalate regulated or safety-critical questions for expert review.
