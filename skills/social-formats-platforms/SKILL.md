# Platform-by-platform content formats and cadence

[← Skills](../README.md) · [Detailed guide](../../growth/social-formats-platforms.md)

## Inputs

Founder stage, target users, actual product, jurisdiction, authorized data, current primary sources and named owner.

## Procedure

1. For X, test concise insight, thread, reply, screenshot demo and founder update.
2. For TikTok, test face-to-camera, UGC, voiceover+b-roll, demo, duet/reaction where licensed.
3. For LinkedIn, test professional case study, carousel/document, founder narrative and technical explanation.
4. For Instagram, test Reel, carousel, Story, highlights and community replies.
5. For YouTube, test searchable tutorial, Shorts and long-form product walkthrough.
6. Create a sustainable calendar with review, repurposing, publishing and measurement; avoid fixed algorithm promises.

## Completion

Deliver channel matrix, reusable format briefs, editorial calendar and review cadence. Distinguish verified facts, hypotheses, observed metrics and unverified leads. Record next review date and responsible owner.

## Safety

No invented traction, fake testimonials, unauthorized data sharing, guaranteed algorithm reach or unsupported legal/tax advice. Use qualified professional review for securities, tax and entity matters.
