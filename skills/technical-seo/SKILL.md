# Technical SEO, indexing and crawl diagnostics — reusable skill

[← Skill library](../README.md) · [Detailed guide](../../design-growth/technical-seo.md)

## Inputs

Live or staging URL, target audience, core user journey, representative devices, current product facts and authorized testing access.

## Procedure

1. Audit indexable URL inventory and choose a canonical for each logical page.
2. Validate robots.txt, noindex directives, sitemap.xml, hreflang and redirect chains.
3. Check SSR/rendered HTML contains primary title, content and links.
4. Verify 404/410 status, pagination and duplicate query parameter behavior.
5. Test mobile usability, Core Web Vitals and accessible navigation.
6. Use Search Console to diagnose coverage rather than promising indexing.

## Output

A prioritized audit: URL/component, problem, impact, evidence, recommended change, owner, expected outcome, verification status and comparable retest.

## Rules

No guaranteed rankings, fabricated testimonials, hidden SEO manipulation or unlicensed copied assets. Distinguish research from tested results. Use the [audit template](../../templates/design-growth-audit.md).
