# AI engine optimization and generative search visibility — reusable skill

[← Skill library](../README.md) · [Detailed guide](../../design-growth/aeo-geo-audit.md)

## Inputs

Live or staging URL, target audience, core user journey, representative devices, current product facts and authorized testing access.

## Procedure

1. Inventory actual user questions and compare to current pages.
2. Publish one accurate answer per intent with authorship, product scope, date and primary references.
3. Check crawlability, robots, canonicals and HTML-rendered content rather than hidden JS-only copy.
4. Use appropriate structured data only when matching visible content and supported by Google guidance.
5. Compare how search and AI systems describe the product; record citations, errors and missing sources.
6. Avoid doorway pages, fabricated reviews, invisible keyword stuffing and claims that llms.txt guarantees ranking.

## Output

A prioritized audit: URL/component, problem, impact, evidence, recommended change, owner, expected outcome, verification status and comparable retest.

## Rules

No guaranteed rankings, fabricated testimonials, hidden SEO manipulation or unlicensed copied assets. Distinguish research from tested results. Use the [audit template](../../templates/design-growth-audit.md).
