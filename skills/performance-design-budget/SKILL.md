# Performance budgets for visually rich interfaces

[← Skills](../README.md) · [Guide](../../design-growth/performance-design-budget.md)

## Inputs

Versioned website/app, core user task, audience, relevant source evidence and authorized testing environment.

## Steps

1. Record real-user or representative mobile baseline for LCP, INP and CLS.
2. Set explicit image/font/JS and third-party performance budgets.
3. Use responsive image sizing, lazy load offscreen media and reserve layout dimensions.
4. Respect reduced motion and avoid animation blocking primary actions.
5. Test slow network, low-memory device and first-time visit.
6. Compare user task completion and metrics before/after.

## Deliverable

Ranked issues with page, evidence, severity, recommended fix, owner, expected effect, release version and observed retest. Separate hypothetical improvements from measured results.

## Safety

No private data in public issues, no invented rankings, reviews or compliance claims, and no copying of protected design assets.
