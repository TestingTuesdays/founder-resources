# Retention, virality and network effects

[← Skills](../README.md) · [Detailed guide](../../growth/retention-virality-network-effects.md)

## Inputs

Founder stage, target users, actual product, jurisdiction, authorized data, current primary sources and named owner.

## Procedure

1. Define activation and meaningful retained action for the product's natural frequency.
2. Build signup cohorts and D1/D7/D30 or weekly/monthly retention where appropriate.
3. Track churn, resurrection, WAU/MAU, paid retention and revenue expansion by segment.
4. Measure invitations sent, accepted and activated; compute viral coefficient only with explicit denominators.
5. Distinguish network effects (product improves with participant density) from referral loops.
6. Test marketplace liquidity, match rate, time to value and quality as network grows.

## Completion

Deliver cohort table, referral funnel, network-density hypothesis and retention interpretation. Distinguish verified facts, hypotheses, observed metrics and unverified leads. Record next review date and responsible owner.

## Safety

No invented traction, fake testimonials, unauthorized data sharing, guaranteed algorithm reach or unsupported legal/tax advice. Use qualified professional review for securities, tax and entity matters.
