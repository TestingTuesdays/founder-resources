# Metadata, social previews and structured data — reusable skill

[← Skill library](../README.md) · [Detailed guide](../../design-growth/metadata-social-preview.md)

## Inputs

Live or staging URL, target audience, core user journey, representative devices, current product facts and authorized testing access.

## Procedure

1. Define unique page title and description aligned to actual visible content.
2. Validate canonical, robots, language, viewport and site name.
3. Add appropriate Open Graph title, description, URL and accessible image; use absolute HTTPS URLs.
4. Add Twitter/X card tags where applicable and test platform previews.
5. Implement JSON-LD only for relevant supported entities; never mark nonexistent reviews, FAQs or prices.
6. Check 200/404, locale, staging noindex and missing image fallback.

## Output

A prioritized audit: URL/component, problem, impact, evidence, recommended change, owner, expected outcome, verification status and comparable retest.

## Rules

No guaranteed rankings, fabricated testimonials, hidden SEO manipulation or unlicensed copied assets. Distinguish research from tested results. Use the [audit template](../../templates/design-growth-audit.md).
