# Moderated usability test

[← Skills](../README.md) · [Topic guide](../../docs/usability.md)

## Objective

Observe whether target users can complete a real task without prompting.

## Required inputs

Product/build, task, persona, consent agreement, safe environment, facilitator and note taker.

## Procedure

1. Recruit participants matching actual use case; agree on consent and recording separately.
2. State the task in user terms without pointing to UI.
3. Observe first action, confusion, mistakes, assistance and whether they finish.
4. Ask open-ended follow-ups after the attempt.
5. Write observable findings with impact and owner.
6. Retest the same task after the fix.

## Done when

Session record containing task outcome, anonymized observations, priority fixes and retest plan.

## Safety and evidence

Use permissioned systems and synthetic data. Obtain research consent where applicable, redact personal information, preserve actual vs expected outcomes, and never state a check passed without running it. Human review remains necessary for high-risk conclusions.
