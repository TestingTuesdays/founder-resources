# Mobile UX heuristics and thumb-reach testing

[← Skills](../README.md) · [Guide](../../design-growth/mobile-ux-heuristics.md)

## Inputs

Versioned website/app, core user task, audience, relevant source evidence and authorized testing environment.

## Steps

1. Observe critical task at narrow widths on real devices.
2. Audit touch targets, sticky controls, keyboard overlap and scroll traps.
3. Check offline/slow network loading, permission denial and form persistence.
4. Verify clear error recovery, back behavior and safe-area insets.
5. Test screen reader, 200% zoom and landscape where relevant.
6. Prioritize fixes using actual task completion, not only screenshots.

## Deliverable

Ranked issues with page, evidence, severity, recommended fix, owner, expected effect, release version and observed retest. Separate hypothetical improvements from measured results.

## Safety

No private data in public issues, no invented rankings, reviews or compliance claims, and no copying of protected design assets.
