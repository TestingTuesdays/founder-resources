# Navigation, information architecture and discoverability — reusable skill

[← Skill library](../README.md) · [Detailed guide](../../design-growth/navigation-information-architecture.md)

## Inputs

Live or staging URL, target audience, core user journey, representative devices, current product facts and authorized testing access.

## Procedure

1. Map primary user tasks and group navigation by user mental models.
2. Audit mobile menu, breadcrumbs, labels, search and deep-link behavior.
3. Run tree testing or first-click tasks without coaching.
4. Check empty states, back navigation and active-state visibility.
5. Ensure keyboard and screen reader navigation is predictable.
6. Measure task completion and time to first correct destination.

## Output

A prioritized audit: URL/component, problem, impact, evidence, recommended change, owner, expected outcome, verification status and comparable retest.

## Rules

No guaranteed rankings, fabricated testimonials, hidden SEO manipulation or unlicensed copied assets. Distinguish research from tested results. Use the [audit template](../../templates/design-growth-audit.md).
