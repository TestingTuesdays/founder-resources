# Visual hierarchy, typography and information scent — reusable skill

[← Skill library](../README.md) · [Detailed guide](../../design-growth/visual-hierarchy.md)

## Inputs

Live or staging URL, target audience, core user journey, representative devices, current product facts and authorized testing access.

## Procedure

1. Identify primary task and primary CTA for each page.
2. Audit heading order, type scale, spacing, contrast, alignment and scan path.
3. Remove competing primary actions and redundant hero copy.
4. Check grouping, whitespace, section labels and progressive disclosure.
5. Verify hierarchy at 320px, 375px, tablet and desktop widths plus 200% zoom.
6. Run a five-second comprehension task and compare actual understanding before/after.

## Output

A prioritized audit: URL/component, problem, impact, evidence, recommended change, owner, expected outcome, verification status and comparable retest.

## Rules

No guaranteed rankings, fabricated testimonials, hidden SEO manipulation or unlicensed copied assets. Distinguish research from tested results. Use the [audit template](../../templates/design-growth-audit.md).
