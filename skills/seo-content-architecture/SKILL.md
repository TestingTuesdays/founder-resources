# SEO content architecture and internal linking

[← Skills](../README.md) · [Guide](../../design-growth/seo-content-architecture.md)

## Inputs

Versioned website/app, core user task, audience, relevant source evidence and authorized testing environment.

## Steps

1. Inventory top user problems and existing URLs; consolidate duplicate intent rather than creating doorway pages.
2. Map hub, comparison, feature, pricing, docs and help pages to one distinct task each.
3. Write truthful descriptive titles, introductions, canonical and related-page links.
4. Link contextually using natural anchor text; prevent orphan pages.
5. Review sitemap, indexation and search queries after release.
6. Refresh stale content with dated primary sources and documented ownership.

## Deliverable

Ranked issues with page, evidence, severity, recommended fix, owner, expected effect, release version and observed retest. Separate hypothetical improvements from measured results.

## Safety

No private data in public issues, no invented rankings, reviews or compliance claims, and no copying of protected design assets.
