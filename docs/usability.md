## Why this matters

Find out whether intended users can complete real tasks without coaching.

## Typical founder mistakes

- Recruiting only founders or friends instead of relevant users
- Asking leading questions such as “Was that easy?”
- Counting preferences as observed task success
- Recording participant screens without explicit consent

## Run these tests

1. **First-time user describes what the product does in their own words.** Write precondition, expected and actual result, build/version, device, severity, owner and retest status.
2. **New user completes activation with no instructions.** Write precondition, expected and actual result, build/version, device, severity, owner and retest status.
3. **User finds and corrects a mistake.** Write precondition, expected and actual result, build/version, device, severity, owner and retest status.
4. **User searches with no results and finds a recovery path.** Write precondition, expected and actual result, build/version, device, severity, owner and retest status.
5. **User cancels or deletes their account, if supported.** Write precondition, expected and actual result, build/version, device, severity, owner and retest status.

## Recommended workflow

Prepare a neutral task and an explicit success criterion. Observe first click, hesitation, errors, assistance and abandonment. Ask open-ended questions only after an attempt. Group findings by severity, assign fixes and retest the same task.

## Do / don't

**Do:** test with representative people and devices, capture non-sensitive evidence, verify failure/recovery, assign ownership and retest the shipped fix.

**Don't:** rely solely on tool scores, copy unverified claims from a vendor, expose customer data, or call an unobserved outcome a passed test.

## Session deliverable

Bring one specific workflow, a safe build/test account, two or more reproducible observations, a severity-ranked fix list, and an agreed follow-up. [Use the session template](../templates/usability-session.md) and [retest sheet](../templates/retest.md).
