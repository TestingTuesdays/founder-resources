# Marketplace dispute and seller quality audit

[← Documentation index](README.md) · [Skill](../skills/marketplace-dispute-operations/SKILL.md)

Marketplace trust requires fair resolution, not only buyer/seller onboarding.

## Step-by-step founder checklist

1. Define dispute types, evidence, moderation authority and appeal.
2. Test fake listing, non-delivery, refund and chargeback with fictional accounts.
3. Verify seller and buyer data isolation.
4. Test timeouts, duplicate payouts and frozen funds.
5. Check accessible status communication and safe escalation.
6. Measure resolution outcomes and policy consistency.

## Test evidence and acceptance

Record build, task, test accounts, environment, expected/actual result, impact, owner and comparable retest. Do not claim a test passed when it has not run. Use synthetic records and authorized environments.
