# Learning pathways for founder product quality

[← Home](../README.md) · [Skills](../skills/README.md)

## No-code and nontechnical founders — 4 weeks

- **Week 1:** map three user journeys, interview users without leading, learn how to write actionable defects.
- **Week 2:** responsive checks, keyboard testing, form validation, browser DevTools and error states.
- **Week 3:** basics of privacy/security, consent, software release and backup/rollback conversations.
- **Week 4:** prioritize bugs, verify released changes, measure retention/activation without vanity claims.

## Technical founders and builders — 4 weeks

- **Week 1:** test pyramid, unit/contract/API checks and basic CI.
- **Week 2:** Playwright, synthetic data, cross-browser, visual regression and accessibility automation.
- **Week 3:** threat model, authz tests, secrets, observability, slow networks and load conditions.
- **Week 4:** release flags, staged rollout, restore/rollback, incident drill and evidence-based retest.

## Role skills

| Role | Core skills |
| --- | --- |
| UX researcher | Recruiting, neutral moderation, synthesis, consent and task metrics |
| QA engineer | Risk prioritization, bug reproduction, test design and automation |
| Product designer | Accessible interaction, information architecture and content clarity |
| Product manager | Acceptance criteria, risk, prioritization, release decisions |
| Founder/CEO | User understanding, truthful launch claims, privacy and ownership |
| DevOps/reliability | CI/CD, logs, rollback, capacity planning and incident response |
| Localization lead | Internationalization, language review, RTL and locale QA |
