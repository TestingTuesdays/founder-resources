## How to use these references

1. Define a user task (e.g., discover a product, onboard, pay, recover an error).
2. Compare 3–5 examples from different products, including mobile and desktop where relevant.
3. Note information hierarchy, CTA prominence, navigation, typography, trust and feedback states.
4. Create original design alternatives; do not copy protected screenshots, illustrations or brands.
5. Test on actual users, devices, slow networks and with keyboard/screen reader support.
6. Document the observed outcome, not only which design you prefer.
