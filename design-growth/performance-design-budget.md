# Performance budgets for visually rich interfaces

[← Design and growth hub](README.md) · [Audit template](../templates/design-growth-audit.md)

Balance animation, imagery and polish with mobile responsiveness and access.

## Actionable procedure

1. Record real-user or representative mobile baseline for LCP, INP and CLS.
2. Set explicit image/font/JS and third-party performance budgets.
3. Use responsive image sizing, lazy load offscreen media and reserve layout dimensions.
4. Respect reduced motion and avoid animation blocking primary actions.
5. Test slow network, low-memory device and first-time visit.
6. Compare user task completion and metrics before/after.

## Evidence checklist

Record URL and build, user/task, expected versus actual, desktop/mobile evidence, severity, change owner and comparable retest. Treat ranking, impressions and conversion changes as observed metrics, never guaranteed outcomes.
