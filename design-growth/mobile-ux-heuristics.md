# Mobile UX heuristics and thumb-reach testing

[← Design and growth hub](README.md) · [Audit template](../templates/design-growth-audit.md)

Optimize one-handed tasks, readability and interrupted mobile journeys.

## Actionable procedure

1. Observe critical task at narrow widths on real devices.
2. Audit touch targets, sticky controls, keyboard overlap and scroll traps.
3. Check offline/slow network loading, permission denial and form persistence.
4. Verify clear error recovery, back behavior and safe-area insets.
5. Test screen reader, 200% zoom and landscape where relevant.
6. Prioritize fixes using actual task completion, not only screenshots.

## Evidence checklist

Record URL and build, user/task, expected versus actual, desktop/mobile evidence, severity, change owner and comparable retest. Treat ranking, impressions and conversion changes as observed metrics, never guaranteed outcomes.
