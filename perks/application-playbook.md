# How to apply for startup credits without wasting runway

[← All perks](README.md) · [Nairobi shortlist](kenya-nairobi.md) · [Perk tracker template](../templates/perk-tracker.md)

## 1. Prepare a reusable company packet

- Legal company name and incorporation jurisdiction; founding date, website/domain email, product description and public demo.
- Founders' roles, customer traction when available, funding amount/stage and investor/accelerator affiliation.
- Current billing provider account, prior promotional credits, projected architecture and infrastructure usage.
- Realistic projected expenses after credits expire. Store sensitive proofs only in private accounts, **never GitHub issues**.

## 2. Filter before applying

Match the company's **jurisdiction, product type, stage, funding, partner ID and prior credits** against provider terms. Check if a card or paid plan is required, whether credits apply to your actual service usage and whether a new account is needed. Prefer direct official links, not referral farming.

## 3. Compare true savings, not headline values

**Realized savings = eligible planned usage covered before credit expiry**, capped by awarded amount. A $100k credit has little practical value if you use only $200/month before expiry. Price the product after the promotional period and track extra seats, taxes, bandwidth, model usage and support plans.

## 4. Apply with verifiable information

Use consistent company/legal details, a working website and concise product explanation. If a partner referral is required, seek an authorized organization ID. Do not invent affiliations, investment rounds or applicant addresses.

## 5. Set controls immediately after approval

Record confidential application ID and billing owner in a private tracker; turn on spend budgets, overage alerts, invoice notifications and limited team permissions. Save award expiry and next review date. Never claim a pending application is approved.

## 6. Maintain the public directory

Only add public terms, official URLs, generic eligibility and a date of review. If the provider changes its policy, correct the entry and link to a source. Individual application decisions, codes and billing details stay private.
